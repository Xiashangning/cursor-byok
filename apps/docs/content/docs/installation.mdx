## 下载应用

前往 [最新版本页面](https://github.com/leookun/cursor-byok/releases/latest)，下载适用于 macOS、Windows 或 Linux 的安装包。

<Callout type="info">
优先使用最新正式版本。发行页面会列出该版本包含的安装包和更新说明。
</Callout>

## 首次启动

<Steps>

<Step>

### 打开 Cursor 配置

启动应用后进入 **Cursor 配置**。如果本地 CA 尚未初始化，页面会显示初始化入口。

</Step>

<Step>

### 初始化本地 CA

点击 **初始化 CA**。本地 CA 用于在你的设备上解析 Cursor 发出的 HTTPS 请求，其文件只保存在本机。

系统要求授权时，按照应用显示的说明在终端中完成信任操作，然后返回应用点击 **我已初始化，刷新**。

</Step>

<Step>

### 添加第一个模型

点击 **添加模型**，选择 OpenAI 或 Anthropic 类型，填写上游服务参数并保存。详细字段说明见[模型配置](./model-configuration.mdx)。

</Step>

<Step>

### 运行连通性测试

点击模型的 **测试**。测试成功后，该模型即可出现在 Cursor 的模型列表中。

</Step>

<Step>

### 首次升级或配置后完全重启 Cursor

首次升级 Cursor 或首次配置模型后，**必须完全退出并重新启动一次 Cursor**。仅关闭窗口不等于退出；请确认 Cursor 进程已经结束后再重新打开。

</Step>

<Step>

### 新建对话

Cursor 重启后新建一个对话，再从模型列表中选择你配置的模型。不要继续使用配置前已打开的对话，也不要选择 **Auto**。

</Step>

</Steps>

## Remote SSH 窗口

启用 Cursor Byok 集成后，Cursor 打开 Remote SSH 窗口时，桌面应用会自动在远端主机提供同号代理端点：

```text
远端 127.0.0.1:<代理端口>
    └── SSH RemoteForward ──> 本地 127.0.0.1:<代理端口> ──> Cursor Byok
```

应用会在自身数据目录生成隔离的 SSH 配置，并让 Cursor Remote SSH 使用它。原有 SSH 配置会被原样包含，Cursor Byok 停止时会恢复原设置。远端只监听回环地址；如果端口无法占用，SSH 会输出告警并继续连接。

在 Cursor 远端服务启动前，同一条 SSH 会话会把本地 CA 证书写入远端用户的 Cursor Byok 私有目录，设置代理与证书环境，按需安装 `uv`，并执行 Semble 官方提供的 Cursor MCP（Model Context Protocol）无交互安装命令。之后由 Cursor 在远端启动 Semble MCP 服务，因此代码搜索读取远端文件系统，不会再拿远端路径到本地查找。

初始化过程也会同步本地 `~/.cursor/skills/` 与 `~/.agents/skills/` 中的用户级 Agent Skills。Cursor 当前将 skill 定义为包含 `SKILL.md` 的目录，该目录还可包含脚本、参考资料和资源文件。项目级 `.cursor/skills/` 或 `.agents/skills/` 已随 Remote SSH 工作区天然存在，因此 Cursor Byok 不会重复复制。

每次新建 Remote SSH 连接时，应用都会重新读取本地用户 skills，并通过加密的 SSH 反向隧道传输。远端注入目录固定为 `~/.cursor/skills/cursor-byok-synced/`；若两个本地用户目录含有同名 skill，以 `~/.cursor/skills/` 为准。若远端用户在任一用户级目录已有同名 skill，会保留远端版本并跳过本地版本。应用会在完整下载后重建专属目录，因此本地删除的 skill 会在下次连接时从注入目录移除，但不会删除无关的远端内容。符号链接不会被跟随或复制。Unix 远端上的目录仅当前用户可访问，普通文件权限为 `0600`，可执行脚本为 `0700`；Windows 远端继承远端用户配置目录的访问控制列表（ACL）。

skill 下载、扫描或写入失败时会在 Remote SSH 输出中告警，但不会阻断 SSH 连接；若暂存阶段失败，远端上一次完整同步的版本会保留。

远端环境需要满足：

- SSH 服务端启用 `AllowTcpForwarding yes`；
- Linux/macOS 远端提供 Bash 和 `curl`，Windows 远端提供 PowerShell；
- 首次配置时可访问 Astral、PyPI 和 Hugging Face，以下载 `uv`、Semble 与模型；
- Windows 主机在 `remote.SSH.remotePlatform` 中配置了正确平台，以便选择 PowerShell 启动路径。

启用 Cursor Byok 或修改代理端口后，请关闭并重新打开已有 Remote SSH 窗口。首次连接安装 Semble 时可能稍慢；如果安装无法完成，Cursor 连接仍会继续，并在 Remote SSH 输出中报告 Semble 错误。

## 验证安装

完成配置后，请确认：

- Cursor 配置页面不再显示 CA 初始化提示。
- 至少一个模型的连通性测试成功。
- Cursor Byok 保持运行。
- 已完全退出并重新启动一次 Cursor。
- 已新建对话，而不是继续使用配置前打开的对话。
- Cursor 模型列表中能看到配置的显示名称。

如果其中任何一步失败，请前往[常见问题](./faq.mdx)。

## 更新

在应用设置中检查新版本，或直接访问 [GitHub Releases](https://github.com/leookun/cursor-byok/releases/latest)。更新前无需删除现有模型配置。
